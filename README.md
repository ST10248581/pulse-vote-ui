# PulseVote Frontend

Frontend for **PulseVote**: a secure, real-time polling application built with **React** and **Vite**.  
Provides a fast, responsive user interface for creating, viewing, and participating in live polls, with secure integration to the backend API.

## Features
- **React + Vite** setup for rapid development and optimized builds
- API integration with backend `/test` endpoint
- Component-based architecture for scalability
- Environment variable support for API URLs
- Modern styling with CSS modules (default setup)
